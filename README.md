## 文档规范

所有对外交付文件（Word / Excel / PPT）均须包含项目专属 logo：

| 文件类型 | logo 位置 | 规格 |
| --- | --- | --- |
| 正式文档（计划书、可行性报告） | 封面居中 | 宽 2.8 cm |
| 过程文档（会议纪要、演示讲稿、个人作业） | 页眉左侧 | 高 0.52～0.62 cm |
| PPT | 封面左上角 | 横版组合标，高 0.62 in |
| Excel | 首个工作表右上角 | 78 × 78 px |

- 图形标：`logo.png`（512×512，透明底）
- 横版组合标：`logo-h.png`（904×200，透明底）
- 深色底版本：`logo-light.png`（512×512）

新建文件时由生成脚本统一插入，不手工添加。

## 会议纪要规范

- **一次会议一份文件**，命名 `SE2026-G22-会议纪要-第NN次-YYYYMMDD.docx`
- 结构固定为两部分：
  1. **上次会议目标检查** —— 目标达成情况表（编号 / 目标 / 责任人 / 期限 / 达成情况 / 说明）、存在的问题与调整措施
  2. **下次会议目标设定** —— 本次会议形成的决议、下次可考核目标（下次例会逐项检查）
- 目标编号连续：第 1 次定 G1-x，第 2 次检查 G1-x 并定 G2-x，依此类推
- 同步输出 Markdown 版供 Git 仓库归档，归档目录 `process/会议纪要/`
